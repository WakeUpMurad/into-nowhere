# Освобождение · Into Nowhere

Веб-прототип символического ритуала: выбрать намерение и комфортную сумму от $1, удержать кнопку и отпустить. Трёхмерный цветок жизни и звёздный тетраэдр реагируют на движение указателя; световые частицы движутся к центру. Музыка включена по умолчанию и начинает звучать после первого касания; её можно выключить. Есть русский, английский и азербайджанский языки.

**Сейчас это демонстрация. Платежи не подключены, деньги не списываются.** Apple Pay, Google Pay и карта в интерфейсе показывают будущий выбор. Сервис коммерческий: планируется направлять 25% суммы каждой оплаты до комиссии на прямую помощь нуждающимся. Выбор пожелания и сумма не означают обещание его исполнения.

## Запуск

Понадобятся Node.js 22.12+ (или совместимая актуальная LTS-версия), npm и Go 1.22+.

```sh
npm ci
```

В одном терминале запустить API:

```sh
npm run dev:api
```

В другом — веб-приложение:

```sh
npm run dev
```

Страница: http://127.0.0.1:5174/. Go API: http://127.0.0.1:8080/api/health. Веб-сервер проксирует `/api` к Go. Если API выключен, интерфейс сообщает об этом, а демонстрационный жест остаётся доступным.

## Структура и проверка

- `apps/web`: React + TypeScript + Vite, Zustand для состояния ритуала, TanStack Query для конфигурации сервера, Radix UI для доступных элементов управления, Three.js для геометрии. Визуальный стиль — блестящее серебристое стекло с лёгкими салатовыми бликами, белая светлая тема и графитовая тёмная. Только фигура светлой темы имеет нежно-розовый оттенок для видимости на белом фоне. По умолчанию включена тёмная тема. Переключатель рядом с языком позволяет выбрать светлую, тёмную или системную тему; ранее выбранная тема сохраняется. Шрифты Manrope и Cormorant Garamond поставляются вместе с приложением.
- `apps/api`: Go API с публичной конфигурацией и валидацией запроса создания оплаты. В демонстрационном режиме корректный запрос возвращает `PAYMENTS_NOT_CONFIGURED`; финансовые записи не создаются.
- `docs/design-notes.md`: палитра, тексты, исследования и ограничения выводов.
- `docs/payment-setup.md`: что владельцу потребуется для подключения платежей.
- `docs/release-plan.md`: порядок публичного запуска для США и Европы и черновик обращения к эквайеру.
- `docs/payments-backend.md`: контракт API и требования к будущему платёжному учёту.

```sh
npm run build
npm test
npm run test:api
```

Сборка веб-приложения находится в `apps/web/dist`. Для будущего платного сервиса потребуется HTTPS, размещение Go API и маршрутизация `/api` к нему.

## Демо на GitHub Pages

Публичное демо: [wakeupmurad.github.io/into-nowhere/](https://wakeupmurad.github.io/into-nowhere/). В репозитории включён источник **GitHub Actions**. Автоматическая сборка и публикация через `.github/workflows/pages.yml` запускается после push в `main` или ручного запуска workflow.

Pages-сборка использует `VITE_DEPLOY_TARGET=github-pages` и `VITE_BASE_PATH=/into-nowhere/`. Это статическое демо без Go API: конфигурация встроена в приложение, платежи выключены. Проверки сумм и сборка должны пройти до публикации. Инструкция и устранение ошибок находятся в [docs/github-pages.md](docs/github-pages.md).

Платный сервис нужно разместить отдельно: [правила GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits) не разрешают использовать Pages как бесплатный хостинг основного коммерческого сервиса или транзакций.

## Мобильные устройства

Веб-интерфейс адаптирован к небольшим экранам. Сцена ограничивает плотность рендеринга, при отсутствии WebGL показывает статичную геометрию, при настройке уменьшения движения отключает анимацию. Музыка требует действия пользователя и приостанавливается при скрытии страницы. Вибрация работает только в браузерах, которые поддерживают её; в Safari на iPhone рассчитывать на неё нельзя.

Для будущих приложений под iOS и Android подходит React Native с Expo. Можно разделить типы, тексты, логику суммы и API, а интерфейс и средства оплаты адаптировать к платформе. Политики оплаты цифровых услуг в магазинах приложений нужно проверить отдельно; веб-эквайринг не заменяет автоматически встроенные покупки.
