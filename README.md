# Освобождение · Into Nowhere

Мобильный веб-сервис символического ритуала: выбрать намерение и комфортную сумму от $1, оплатить обычными TON и отпустить. Трёхмерный цветок жизни и звёздный тетраэдр реагируют на движение указателя; световые частицы движутся к центру. Музыка включена по умолчанию и начинает звучать после первого касания; её можно выключить. Есть русский, английский и азербайджанский языки, светлая и тёмная темы.

- **Основной сайт:** [into-nowhere.murad-losangeles.workers.dev](https://into-nowhere.murad-losangeles.workers.dev/) — React-приложение, TON Connect и сервер платежей Cloudflare Worker с постоянной базой D1.
- **Демонстрация:** [wakeupmurad.github.io/into-nowhere/](https://wakeupmurad.github.io/into-nowhere/) — статическая версия GitHub Pages с отключёнными платежами.

Долларовая сумма — ориентир для расчёта; перевод и возможный возврат выполняются **в TON основной сети**, сетевую комиссию отдельно показывает кошелёк. Создание публичного счёта и выбор кошелька проверены. Бесплатный персональный `TONAPI_KEY` добавлен как зашифрованный секрет Cloudflare, приём включён в конфигурации (`PAYMENTS_ENABLED=true`). **Доступ сервера к индексатору проверен: TON API возвращает HTTP 200. Реальный контрольный перевод владельцем ещё не выполнен.** Создание счёта или открытие кошелька не подтверждают получение денег. Apple Pay, Google Pay, карта и USDT сейчас не подключены.

Сервис коммерческий и не обещает исполнения пожеланий. **25% каждого полученного платежа до комиссий выделяется на прямую помощь людям**, 75% — доход и расходы сервиса. Доля помощи учитывается точно в TON; оператор выполняет помощь и возвраты вручную. Отчётов об оказанной помощи пока нет. Контакт: murad.losangeles@gmail.com.

## Локальный запуск TON-версии

Понадобятся Node.js 22.12+ и npm. После установки зависимостей собрать интерфейс и применить локальные миграции:

```sh
npm ci
npm run build
npx wrangler d1 migrations apply into-nowhere-payments --local
npm run dev:payments
```

Страница: http://127.0.0.1:8787/. Wrangler использует локальную базу, но платёжный маршрут настроен на mainnet и настоящий адрес получателя. **Локальная база не делает перевод тестовым:** для разработки без реальных платежей установите `PAYMENTS_ENABLED="false"` в локальном `.dev.vars`. После изменения интерфейса повторите сборку. Ключи поставщиков при необходимости добавляются только как серверные секреты.

Для работы над интерфейсом с подготовленным Go API понадобятся также Go 1.22+: запустите `npm run dev:api` и отдельно `npm run dev`. Веб-сервер http://127.0.0.1:5174/ проксирует `/api` к Go на порту 8080; Go по умолчанию работает без реальных платежей. Это отдельный маршрут разработки, не опубликованный TON-сервер.

## Структура и проверка

- `apps/web`: React, TypeScript, Vite, Zustand, TanStack Query, Radix UI и Three.js. Серебристое стекло с лёгкими салатовыми бликами; фигура светлой темы имеет нежно-розовый оттенок. По умолчанию включена тёмная тема. Шрифты Manrope и Cormorant Garamond поставляются вместе с приложением.
- `apps/payments-worker`: TON-счета, свежий курс, идемпотентность, приватные квитанции и подтверждение входящих переводов по данным блокчейна. D1 хранит заказы; проверка выполняется при чтении квитанции и раз в минуту по расписанию.
- `apps/api`: подготовленный Go-маршрут Epoint. Его включение требует одобренного аккаунта продавца, договора и серверных ключей; сейчас карточные платежи не активированы.
- [docs/ton-payments.md](docs/ton-payments.md): публикация, резервная копия, проверка реального перевода и обязанности оператора.
- [docs/payment-setup.md](docs/payment-setup.md) и [docs/payments-backend.md](docs/payments-backend.md): дальнейшее подключение эквайринга и контракт Go API.
- [docs/design-notes.md](docs/design-notes.md), [docs/release-plan.md](docs/release-plan.md): дизайн и план продвижения.

```sh
npm test
npm run test:payments
npm run check:payments
npm run test:api
npm run build
```

Для обновления основного сайта после проверок: `npm run deploy:payments`. Подробный порядок, включая миграции и ограничения бесплатного размещения, — в руководстве TON.

## GitHub Pages и мобильные устройства

`.github/workflows/pages.yml` публикует демонстрацию после push в `main` или ручного запуска workflow. Сборка использует `VITE_DEPLOY_TARGET=github-pages` и `VITE_BASE_PATH=/into-nowhere/`; обращения к платёжному API и настоящие платежи отключены. [Инструкция GitHub Pages](docs/github-pages.md). Основной коммерческий сервис размещён отдельно в Cloudflare: [ограничения GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits).

Сцена адаптирована к небольшим экранам, ограничивает плотность рендеринга, при отсутствии WebGL показывает статичную геометрию и учитывает уменьшение движения. Музыка требует действия пользователя и приостанавливается при скрытии страницы. Вибрация зависит от браузера; в Safari на iPhone на неё рассчитывать нельзя.

Для будущих приложений iOS и Android подходит React Native с Expo. Можно разделить типы, тексты, логику суммы и API, а интерфейс и оплату адаптировать к платформе. Правила оплаты цифровых услуг в магазинах приложений проверяются отдельно перед выпуском.
